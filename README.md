# 📊 Atualizando Relatório Financeiro com Foco na Experiência do Usuário

## 📌 Descrição

Este projeto foi desenvolvido para o desafio da DIO, com o objetivo de aplicar melhorias visuais e de usabilidade em um relatório financeiro previamente construído no Power BI.

O foco principal do desafio consistiu em aprimorar a experiência do usuário (UX), tornando a navegação mais intuitiva, os visuais mais organizados e a apresentação dos dados mais eficiente para análise.

---

## 🎯 Objetivos

- Melhorar a experiência do usuário no relatório.
- Aplicar boas práticas de design e visualização de dados.
- Reorganizar elementos visuais para aumentar a legibilidade.
- Criar mecanismos de navegação entre páginas.
- Tornar a análise mais intuitiva e interativa.

---

## 🛠️ Melhorias Implementadas

Durante o desenvolvimento foram realizadas as seguintes alterações:

### Organização dos Elementos

- Reposicionamento dos visuais.
- Ajuste do alinhamento dos componentes.
- Melhor distribuição dos elementos na página.
- Aplicação de conceitos de hierarquia visual.

### Experiência do Usuário (UX)

- Melhoria da navegação entre páginas.
- Inserção de botões interativos.
- Destaque visual para páginas selecionadas.

### Visualização dos Dados

- Ajuste de gráficos existentes.
- Modificação do gráfico de área.
- Criação de matriz de descrição de vendas.
- Adequação da segmentação de dados.
- Aplicação de melhorias de contraste para facilitar a leitura.

### Design

- Utilização dos conceitos de:
  - Posicionamento
  - Contraste
  - Segmentação dos dados
  - Proporção áurea

O objetivo foi facilitar a interpretação das informações e tornar o relatório visualmente mais agradável.

---

## 📑 Estrutura do Relatório

O relatório foi desenvolvido com três páginas principais:

### Página 1
- Visão geral dos indicadores financeiros.
- Aplicação das melhorias de layout e navegação.

### Página 2
- Adequação visual seguindo o mesmo padrão aplicado na primeira página.
- Padronização dos elementos e identidade visual.

### Página 3
- Continuidade da experiência de navegação.
- Consolidação das análises complementares do relatório.

---

## 🚀 Funcionalidades Implementadas

- Botões de navegação entre páginas.
- Segmentadores de dados.
- Destaque visual para seleção de páginas.
- Navegação intuitiva entre relatórios.
